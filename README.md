# project_drawing_classifier Flow

This project defines a declarative CrewAI Flow in `src/project_drawing_classifier/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/project_drawing_classifier/flow.yaml` to change the flow. Add reusable crews under `src/project_drawing_classifier/crews/`, custom Python tools under `src/project_drawing_classifier/tools/`, and shared knowledge files under `src/project_drawing_classifier/knowledge/`.
